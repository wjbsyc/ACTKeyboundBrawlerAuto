# ACTKeyboundBrawlerAuto（魔光键影助手）

----

ACTKeyboundBrawlerAuto 是一个用于金碟游乐场“魔光键影”玩法的 ACT 插件。插件会从游戏网络数据中识别当前题目，并可在玩法进行时模拟键盘输入答案。

----

## 功能说明

* 从网络数据中识别魔光键影的题目与相关事件。
* 使用模拟键盘输入的方式填写答案。
* 输入完成后，在设定的最小/最大延迟范围内随机等待，再提交答案。
* 识别“禁止打字”相关机制；机制生效期间暂停输入，安全后再继续。
* 经过测试，逗号等标点符号不影响判定结果，所以每次正式输入答案前，会先通过键盘输入一个标点符号前缀，用于保持键盘活动(防踢)。
* 玩家手动按键或使用输入法时，自动输入会暂时避让。
* 支持独立日志、原始调试日志与未知题目记录。

----

## 使用说明

1. 先确认 ACT 已正常加载并启用 FFXIV ACT Plugin，游戏网络解析功能可用。
2. 将发布包中的插件文件保持在同一目录，然后在 ACT 的插件管理中加载 `ACTKeyboundBrawlerAuto.dll`，并启用该插件。
3. 切换到 ACT 的“魔光键影”页签。
4. 勾选 `启用监听`。插件状态显示为监听中后，即可进入金碟游乐场魔光键影玩法。
5. 如需自动输入，勾选 `启用自动输入`。
6. 根据需要设置 `最小延迟(秒)` 与 `最大延迟(秒)`。插件会在输入完成后，在该范围内随机等待再提交。
7. 保持 FF14 为前台窗口。自动输入只在 FF14 前台时工作，不会向 ACT 或其他窗口发送按键。
8. 开始魔光键影玩法。插件识别到可输入题目后会自动填写并提交。
9. 需要手动输入时可以直接按键；插件会检测到手动输入并暂停自动动作。

----

## 测试输入

点击插件页签中的 `测试输入` 按钮：

1. 按钮开始 3 秒倒计时。
2. 立即切换到 FF14 前台。
3. 倒计时结束后，插件会通过键盘输入一个标点符号前缀和测试文本 `啦哩吼`。
4. 测试只写入输入框，不发送回车提交。

如果测试没有输入，请优先检查 FF14 是否在前台，以及 ACT 与 FF14 是否存在权限差异。

## 插件设置

| 设置 | 说明 |
| --- | --- |
| 启用监听 | 开启网络数据识别与题目记录。 |
| 写独立日志 | 在插件目录的 `logs` 文件夹中写入插件日志。 |
| 记录原始HEX | 记录调试用的原始数据，通常仅在排查问题时开启。 |
| 记录所有玩家回执 | 除本机玩家外，也记录其他玩家的答题回执。 |
| 启用自动输入 | 开启自动填写与自动提交。 |
| 最小延迟(秒) | 两次输出之间允许的最小等待时间。 |
| 最大延迟(秒) | 输入完成后的随机等待上限。 |

----

## 禁止打字机制处理

魔光键影中存在会使输入无效或带来惩罚的“禁止打字”机制。

插件识别到相关机制后，会：

* 暂停新的自动输入。
* 暂停尚未提交的输入动作。
* 等待机制结束并留出安全缓冲。
* 机制解除后自动恢复输入调度。

如果插件状态显示“禁止打字窗口中”，此时没有输入是预期行为。

----

## 日志与题目文件

* 插件日志位于插件目录的 `logs` 文件夹。
* `打开日志目录` 按钮可以直接打开日志文件夹。
* `打开词表` 按钮可以打开当前使用的词表文件。
* `重载词表` 按钮用于词表变更后重新加载。
* 未知题目会记录到 `unknown_words.json`；如需反馈问题，可以点击 `保存未知表` 后提供该文件。
